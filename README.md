# Retail Data Workbench

Upload messy retail CSVs -> clean them safely -> chat with the data and get answers backed by evidence.

> Status: Day 1 - project skeleton + messy data generator.

## Quick start
```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python scripts/generate_messy_data.py
```
