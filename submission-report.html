1. Strict Code-vs-AI System Boundary

Every transformation and query follows a five-stage pipeline where the model never touches raw CSV cells or arithmetic.

Zero Hallucinated Math
STAGE 01

PII-Safe Profiler

Reads CSVs as raw text to preserve leading zeros, masks customer PII, and counts prompt injections without copying text.

STAGE 02

Plan-Before-Mutate

Generates stable step IDs, reasons, and risk levels before changing a single cell. Re-running on clean data yields 0 changes.

STAGE 03

Retail Intelligence

Normalizes aliases with confidence thresholds, rejects many-to-many join fan-outs, and computes signal-weighted health scores.

STAGE 04

Allow-List Validator

Rejects unknown fields, raw SQL keys, private PII columns, and excessive row limits before execution ever begins.

STAGE 05

Grounded Evidence

Executes validated plans in pandas, saves SQLite session traces, and falls back to rules automatically if Gemini fails.

Explicit Uncertainty Policy

Handling Ambiguous Dates, Categories & Questions

1. Slash Dates (05/01/2026): Checks column evidence (e.g., 27/09) to prove day-first parsing before converting to ISO format.

2. Category Confidence: High-certainty aliases ("Tee" → "T-Shirt") normalize automatically, while "Denim" (75% confidence) stays flagged for human review.

3. Vague Chat ("show sales"): Asks "Do you mean revenue, units, or orders?" instead of guessing.

Zero-Downtime Fallback

Simulated Provider Outage (GEMINI_API_KEY="bad-key")

When Gemini is unreachable, times out, or returns invalid JSON, the adapter performs bounded retries and hands control to the deterministic rules_planner.

Result: The user still gets the exact validated revenue breakdown, and :trace transparently records the fallback reason.

Prompt Injection & Malicious Plan Defense

1. CSV Cell Injection: Strings like IGNORE ALL PREVIOUS INSTRUCTIONS inside product names are counted by the profiler and never sent to the LLM.

2. Unsafe Plans Blocked: Requests asking for 10,000,000 rows, raw SQL execution keys, customer emails, or unavailable profit margins are rejected before execution.
